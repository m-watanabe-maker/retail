# 小売業向け 法人AI研修 LP（株式会社UX-HATCH）

単一の `index.html` で動作する静的ページです（ビルド不要）。

## GitHub Pages での公開手順
1. このフォルダ内のファイル（`index.html` / `README.md`）をリポジトリのルートにアップロード
2. リポジトリの Settings → Pages → Branch を `main` / `(root)` に設定して Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開

## 公開前の確認
- 受講者の声・アンケート数値の掲載許可
- 問い合わせフォームのリンク先（`index.html` 内の form-mailer の URL）
